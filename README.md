# Student Performance Prediction

A machine learning project that predicts student academic performance using student demographic, social, and academic information.

## Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
- Streamlit

## Dataset

Student Performance Dataset from the UCI Machine Learning Repository.

## Goal

To analyze student data and build machine learning models that predict final student performance.
